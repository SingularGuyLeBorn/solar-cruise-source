# SOLAR CRUISE · 太阳系漫游

第一人称/第三人称的太阳系曲率飞船体验。驾驶“先驱者号”离开地球，在按真实尺寸比例搭出的太阳系里飞行、跃迁、切换左右两台全息投影（馆藏 / 太阳系），或者切到 Cesium 俯瞰地球。

![驾驶舱与两台全息投影](docs/cockpit.png)

![馆藏投影库](docs/holo-gallery.png)

## 这是什么

这是一个可玩的太空探索纵切片，不是完整太空模拟器。你现在能做这些事：

- 在驾驶舱和第三人称视角之间切换，手动飞行或交给 PID 自动驾驶。
- 用真实行星半径与真实行星轨道距离游览太阳系；主要卫星使用真实轨道半径。
- 打开多套导航/全息界面：轨道图、驾驶舱左右两台实体投影（左侧馆藏玻璃投影 / 右侧太阳系粒子环）、全屏 3D 全息星图。
- 在馆藏投影库浏览与切换 20 件三星堆真实扫描点云；抽象粒子形态已退出投影界面。
- 手动打开六边形离子护盾（默认关闭），处理太阳活动、随机小行星接近和护盾撞击。
- 在手机上用触控完成所有操作。

## 第一次出航

1. 启动项目，点击“进入驾驶舱”。
2. 按 `W` 前进推力；按住 `S` 越过 0 会进入反推倒退；按 `1`–`9` 直接进曲率档；按 `Shift` 加力。
3. 看屏幕顶部当前目标，按 `J` 打开全息星图选目标，按 `Space` 跃迁过去。
4. 按 `O` 收放两台投影；投影卡顶部 tab 在馆藏 / 太阳系之间切换，投影卡里的 `打开馆藏库` 打开 20 件扫描投影库。
5. 按 `H` 打开/收起护盾。听到/看到 MAYDAY 时注意小行星来袭；`K` 可主动触发一次测试。
6. 按 `C` 进入 Cesium 地球视图；按 `V` 切换驾驶舱/第三人称；按 `M` 开关座舱撞击音效。

驾驶舱里是**两台独立投影**：左侧馆藏投影把 20 件真实扫描以 **3D 点云**悬浮在透明玻璃背板前（自转、上下浮动、扫描带扫过，背板只做边框与铭牌，不压平粒子），右侧太阳系投影保留粒子星球导航环；点哪台投影或投影卡顶部的 `馆藏 / 太阳系` tab，哪台就获得滚轮与方向键焦点。馆藏默认每 8 秒自动巡展下一件，太阳系默认每 9 秒巡游下一个天体；任何手动选择都会重新计时，打开馆藏库时自动切换暂停。

### 手机

- 单指拖动可环视；左下虚拟摇杆控制俯仰 / 偏航。
- **左下虚拟摇杆和底部双向油门常驻**，不放进面板：油门条左半段为倒退，右半段为前进。
- 其余指令在右下角 `操作` 卷轴里，点开展开成 5 列高密度按钮（WARP、滚转、HOLD/FLY/POINT、扫描、跃迁、星图、投影、全停、撞击），再点收起。
- 顶部导航只剩视角、护盾、引擎、`投影`、操作和 Cesium；星图从投影卡或小地图按钮进入。
- 移动端投影是一个**紧凑玻璃卡**（不是全宽），顶部 `馆藏 / 太阳系` tab 切换；卡内的预览窗是真正的 3D 点云 / 3D 太阳系，不是平面缩略图。全屏星图与馆藏库的预览同样是 3D 点云。
- 面板宽度按内容分级：投影卡、扫描卡、小地图、操作卷轴互不同宽，避免所有面板都撑满横向。

## 小行星、彗星与撞击：真实到什么程度？

这一节直接回答“是不是真实数据”的问题，避免 README 夸大：

| 对象           | 当前实现                                                                                                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 小行星带       | 程序化分布：90 个实例共用同一个 Helion 岩石模型，另有 1200 个环境尘埃点。**不是**逐颗真实小行星轨道或真实形状。                                                                    |
| 小行星尾流     | **没有**：背景尘埃不是单颗小行星的尾流；来撞击的测试小行星也没有拖尾。                                                                                                             |
| 柯伊伯带       | 1600 个示意点，分布在约 30–50 AU，不是逐个真实天体。                                                                                                                               |
| 撞击测试小行星 | 程序化十二面体 + 红色标记，不是真实小行星模型。                                                                                                                                    |
| 四颗彗星       | 使用公开轨道要素做近似轨道；67P 使用真实 67P 形模，其余三颗目前共用 Tempel 1 形模作替身，并非各自真实核形。                                                                        |
| 彗尾           | 有：固定种子生成的 240 点抗太阳方向粒子锥，带辉光。方向会随太阳位置变化，但长度不随日心距/太阳活动变化，没有离子尾/尘埃尾分离，也没有太阳风动力学。                                |
| 撞击特效       | 有：护盾六边形变形与颜色渐变、点光 sprite、全屏白色冲击闪光、MAYDAY 警报、相机方向性抖动、座舱独立晃动、程序化金属嘎吱与结构闷响、船体角冲量。**没有**碎片、火花、爆炸或手柄震动。 |
| 第一人称震动   | 有。撞击按相对速度、法向入射角和小行星质量算出 severity，驱动相机抖动、座舱模型独立晃动和音效强度；角冲量由切向速度计算，不再用随机数。护盾蜂窝变形仍只在第三人称可见。            |

所以：**小行星带和撞击体是程序化为主，彗核/彗星轨道是真实资料与模型混合，彗尾是程序化近似。**

### 撞击反馈现在怎么算

撞击发生时不是固定播放一段动画，而是先算飞行状态：

- **相对速度** = 小行星世界速度 − 飞船世界速度。
- **法向占比** = |v_rel · n| / |v_rel|；正面撞比擦边撞更重。
- **等效质量** = 小行星尺寸³；每次接近的尺寸会随机。
- **估算能量** = ½ · m · v_rel²。

这些量合成 `severity`，再分别驱动：护盾形变/颜色、相机方向性抖动、座舱模型独立晃动、撞击音效强度与声像、船体推离速度，以及由切向速度计算出的角冲量。音效在第一次点击后由 Web Audio 解锁；`M` 静音。

如果你要更真实的一版，下一步应优先补：单颗小行星的粒子尾流、碎片/火花/冲击波、控制器震动，以及把彗尾长度绑定到日心距和太阳活动。

## 世界与全息

- 行星/矮行星使用真实公里半径按同一比例换算；行星轨道使用真实半长轴；主要卫星使用真实轨道半径，少数不规则卫星仍是近似值。
- 行星贴图来自公开真实地图；月球/火星有真实地标、NASA 登月舱与毅力号模型。
- 驾驶舱右侧太阳系投影的环形图包含太阳与全部行星/矮行星，均为贴图采样粒子星球，不使用实心球；左侧馆藏投影是真实的 3D 扫描点云悬浮在玻璃背板前，不使用抽象粒子雕塑，也不把点云烤成平面贴图。
- 全屏星图中央是选中天体的真实贴图采样粒子重建；外圈所有天体可点击/滚轮/触控选择。
- 馆藏库含 20 件三星堆真实扫描点云；打开库后是左右分栏：左侧 3D 点云玻璃屏（桌面 16,000 点 / 手机 8,000 点），右侧是**纯透明的索引面板**，选项列表独立滚动、头尾固定。馆藏颜色是展陈配色，不是文物表面测色复原。19 种程序化形态不再出现在投影界面。

## 护盾与危险事件

- 连续共边蜂窝护盾：闭合球面保留拓扑必需的 12 个五边形，其余为正六边形；撞击区域按强度向内形变并出现青→琥珀→红色渐变。
- 随机小行星接近/撞击、太阳风与耀斑/电磁干扰、MAYDAY 警报。
- 护盾蜂窝在第三人称可视；第一人称会看到 HUD 闪光、相机抖动、座舱独立晃动，并听到随撞击强度变化的嘎吱声。

## 运行

需要 Node.js 22.12+（或 20.19+）。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

`postinstall` 会把 Cesium 静态资源复制到 `public/cesium/`（不提交到 Git）。调试参数：`?debug=1` 提供 `window.__cruise`；`?ship=<seed>` 切换船体变体；`?hazards=0` 关闭随机小行星。

## 已知限制

- 小行星带、柯伊伯带、彗尾、撞击小行星均为程序化/示意级，不是科学仿真。
- 撞击仍缺少碎片、火花、爆炸和手柄震动；音效为程序化合成，不是实录材质声；第一人称看不到护盾蜂窝形变。
- 彗尾长度、尘埃尾/离子尾、彗核活动未做物理耦合；只有 67P 使用真实核形，其余彗星共用形模。
- 全息馆藏是真实扫描点云，但部分来源未逐件标注许可证；公开部署或商业使用前请核对 `public/artifacts/CREDITS.md`。
- Cesium 依赖在线服务，没有内置离线影像。
- 移动端、2K/4K 贴图、全息粒子和 Cesium 分别有 GPU/内存开销；DPR 上限 1.35。
