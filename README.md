# SOLAR CRUISE · 太阳系漫游

一个第一人称/第三人称的太阳系曲率飞船体验：坐进驾驶舱，飞向月球、火星、木星、土星，或者打开 Cesium 俯瞰地球。

![Cockpit](docs/cockpit.png)

> 当前是 **v0.1 可玩纵切片**：核心飞行、相对论时钟、曲率跳跃、驾驶舱、离子护盾、太阳系主要天体、月球/火星地标、木星大红斑、土星环与 Cesium 地球均已接入。更多卫星、地表细节与资产会在后续迭代。

## 已实现

- **飞船与驾驶舱**：原创“先驱者号”造型，完整驾驶舱框、玻璃座舱、中央操纵杆、油门杆、多块动态仪表屏、侧控制台、全息地球。
- **双视角**：驾驶舱第一人称 / 第三人称追尾视角；玻璃使用双面透明材质。
- **曲率飞行**：W/S 油门、数字键 0–9 曲率档位、Shift 加力、X 全停；引擎尾焰随油门/曲率变化，转向时尾焰同步偏转。
- **相对论时钟**：实时显示速度、洛伦兹因子 γ、外部时间与飞船固有时；曲率档位下显示工程模型的“曲率泡固有时”。
- **空间跳跃**：J 打开目的地菜单，Space 执行曲率跳跃；跳跃过程有星线拉伸与过渡。
- **离子护盾**：六边形能量壳，冲击时产生涟漪；H 开关，K 模拟冲击波。平时隐藏以免遮挡视线，受击/开启时闪现。
- **太阳**：分层光球/日冕着色器、太阳黑子、日珥/耀斑脉动、体积感光晕。
- **太阳系**：8 大行星 + 冥王星、谷神星、妊神星、鸟神星、阋神星；约 100 颗卫星（含全部主要卫星 + 多颗不规则卫星）；小行星带、柯伊伯带/奥尔特云示意、4 颗著名彗星。
- **真实轨道参数**：轨道周期、偏心率、倾角、升交点、自转周期与自转轴倾角按公开数据设置；可视距离做了游戏化压缩。
- **行星细节**：木星大红斑/小红斑、土星环、地球昼夜与云层、火星奥林匹斯山/水手号峡谷、月球阿波罗/月球车/嫦娥四号地标（标签 + 信标 + 简化模型）。
- **Cesium 地球**：真实卫星影像、ArcGIS 地形、NASA GIBS 城市灯光；紧凑座舱框叠在 Cesium 画面上，可鼠标拖拽/滚轮环绕地球。
- **动态仪表**：导航、飞行、系统、扫描四类屏幕；目标、距离、速度、γ、护盾、引擎、时间与邻近天体实时刷新。

## 操作

| 按键      | 功能                                                     |
| --------- | -------------------------------------------------------- |
| `W` / `S` | 油门加 / 减                                              |
| `Shift`   | 加力                                                     |
| `X`       | 油门与曲率归零                                           |
| `0`–`9`   | 直接设定曲率档位                                         |
| 方向键    | 俯仰 / 偏航                                              |
| `A` / `D` | 滚转                                                     |
| 鼠标      | 点击画面锁定后转向；`Esc` 释放                           |
| `Space`   | 跳跃到当前目标                                           |
| `J`       | 打开 / 关闭目的地菜单                                    |
| `V`       | 驾驶舱 / 第三人称                                        |
| `H`       | 离子护盾开关                                             |
| `E`       | 引擎点火 / 关闭                                          |
| `T`       | 星历时间倍率（暂停 / 1× / 1 天/秒 / 10 天/秒 / 1 年/秒） |
| `R`       | 扫描邻近天体（结果显示在驾驶舱扫描屏）                   |
| `C`       | 进入 / 查看 Cesium 地球视图                              |
| `K`       | 模拟一次冲击波（护盾涟漪）                               |
| `P`       | 飞行手册                                                 |

驾驶舱内可以直接点击护盾 / 引擎按钮；HUD 顶部按钮也可切换视角、护盾、引擎、Cesium 和帮助。

## 快速开始

要求 Node.js 22.12+（或 20.19+）。

```bash
npm install
npm run dev
```

`postinstall` 会把 Cesium 的静态资源复制到 `public/cesium/`（该目录不提交到 Git）。生产构建：

```bash
npm run build
npm run preview
```

## Cesium 地球

- 进入方式：HUD 顶部 `CESIUM 地球`，或按 `C`；返回按顶部 `返回太空`。
- 影像：Esri World Imagery（Esri / Maxar / Earthstar Geographics）。
- 地形：ArcGIS WorldElevation3D；不可用时自动退化为椭球。
- 夜景：NASA GIBS `VIIRS_CityLights_2012`。
- 需要网络；离线时 Cesium 视图会退化为空白并提示加载失败。其他太空场景仍可用。
- 地球模式使用紧凑座舱框，隐藏中央仪表台，保证地球视野完整；回到太空模式恢复完整驾驶舱。

## 已知限制 / 下一步

- **卫星目录**：已覆盖全部主要球形卫星与多颗不规则卫星，但并非每颗已命名小卫星都有独立轨道；后续会补全。
- **地表细节**：月球脚印、月球车、火星车、奥林匹斯山目前是**程序化简化模型 + 标签/信标**，不是测绘级资产；可以贴近观察，但细节有限。
- **驾驶舱**：按参考图做了多屏仪表台、座舱框、操纵杆、油门与灯光，但属于原创风格还原，不是逐像素复刻。
- **曲率/相对论**：洛伦兹因子与时间膨胀按狭义相对论计算；曲率档位是游戏化的“曲率泡”工程模型，不是真实物理。
- **Cesium**：依赖外部在线服务；没有内置离线地球影像。
- **战斗**：暂无武器/敌人；`K` 仅用于演示护盾冲击涟漪。
- **性能**：Cesium + three.js + 后处理对 GPU 有要求；移动端未做完整适配。

后续方向：补全卫星、着陆地表、更多地标与真实模型、驾驶舱交互细化、音效、VR、行星环阴影与大气散射。
