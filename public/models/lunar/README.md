# Lunar survey rover

`survey-rover.glb` — six-wheel solar survey rover from
[vaibhavpandeyvpz/kylr](https://github.com/vaibhavpandeyvpz/kylr), licensed
under the Apache License 2.0 (see `LICENSE`). The model is original work for
that project and is re-used here as a fictional modern lunar rover at the
Oceanus Procellarum outpost. It is not an Apollo Lunar Roving Vehicle.

Source file: `game/assets/models/environments/lunar_rover/lunar_rover.glb`.
