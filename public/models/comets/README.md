# Comet nuclei

- `67p.glb` — 67P/Churyumov–Gerasimenko shape model, converted from the
  ESA/Rosetta/MPS OSIRIS shape data via
  [veronicanardy/caeli-view](https://github.com/veronicanardy/caeli-view)
  (repository metadata: MIT). Shape data credit: ESA/Rosetta/MPS for OSIRIS
  Team MPS/CSNSM/UNIBW/TU Braunschweig/UP/LA Sage/IAAS/SSO/INTA/UPM/DASP/IDA.
- `tempel1.glb` — 9P/Tempel 1 shape model, NASA/JPL/UMD (Stardust mission);
  conversion via the same repository.

The baked materials in this project are simplified dark regolith colors and
do not claim to be measured comet surface color.
