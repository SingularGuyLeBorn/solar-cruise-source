# NASA surface models

- `apollo-lunar-module.glb` — NASA 3D Resources, Apollo Lunar Module.
- `perseverance.glb` — NASA 3D Resources, Mars 2020 Perseverance Rover.
- `phobos.glb` — Phobos shape/texture model, adapted from
  [openmars-app/openmars](https://github.com/openmars-app/openmars)
  (MIT, see `LICENSE-openmars.txt`). Original Phobos imagery/shape data:
  NASA/JPL/USGS and the Viking/Mars Global Surveyor teams.

NASA 3D Resources: https://github.com/nasa/NASA-3D-Resources

NASA content is free to use under NASA's media usage guidelines; NASA does not
endorse this project. https://www.nasa.gov/nasa-brand-center/images-and-media/
