# Moon surface maps

Real spacecraft maps added for the major moons:

- `phobos.jpg`, `deimos.jpg` — global maps by Askaniy, derived from NASA/JPL
  imagery; CC BY-SA 3.0. Source: Wikimedia Commons
  (`Phobos map by Askaniy.png`, `Deimos map by Askaniy.png`).
- `iapetus.jpg` — NASA/JPL/SSI Cassini color map (public domain).
- `miranda.jpg` — NASA/JPL/USGS Voyager mosaic (public domain).
- `ariel.jpg`, `umbriel.jpg`, `titania.jpg`, `oberon.jpg` — NASA/JPL/Caltech/USGS
  Voyager maps (public domain).

The remaining moon maps in this directory are Solar System Scope CC BY 4.0
maps; the original project credits are in `THIRD_PARTY_NOTICES.md`.
